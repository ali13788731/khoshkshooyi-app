# دستیار خشکشویی — نسخه‌ی بومی اندروید

این پوشه، بازنویسی کامل اپ (که قبلاً یک صفحه‌ی HTML داخل پوسته‌ی Capacitor بود) به یک
پروژه‌ی واقعی Android Studio با **Kotlin + Jetpack Compose** است. هیچ HTML/JS/WebView‌ای
در کار نیست.

## چرا این کار انجام شد

نسخه‌ی قبلی از طریق پلاگین وب `@capacitor-community/speech-recognition` به میکروفون
دسترسی می‌گرفت. روی اندروید ۱۱ به بعد، بدون تعریف صریح `<queries>` برای
`android.speech.RecognitionService` در Manifest، اپ سرویس تشخیص گفتار گوگل را پیدا
نمی‌کرد و درخواست ضبط، بی‌صدا (silent) شکست می‌خورد — همان «مشکل میکروفون». نسخه‌ی
بومی مستقیماً از `android.speech.SpeechRecognizer` خود سیستم استفاده می‌کند و این
مشکل کلاً از ریشه حل شده.

## ساختار پروژه

```
app/src/main/java/ir/khoshkshooyi/assistant/
  data/        مدل‌های داده (Shop, Customer, Order) + ذخیره‌سازی محلی (SharedPreferences+JSON)
  ai/          کلاینت OpenAI/چت‌جی‌پی‌تی (چت با gpt-4o-mini، تبدیل متن‌به‌گفتار ابری، اعتبارسنجی کلید)
  voice/       تشخیص گفتار بومی اندروید + پخش صدا (ابری با فallback به TTS خود گوشی)
  ui/screens/  صفحات: ورود، داشبورد، ثبت سفارش (+ دستیار صوتی)، فاکتورها، مشتریان، تنظیمات، چاپ فاکتور
  ui/theme/    رنگ‌ها و تم که دقیقاً با نسخه‌ی قبلی هماهنگ است
  MainActivity.kt   نقطه‌ی ورود + گرفتن مجوز میکروفون
  AppViewModel.kt   وضعیت کلی اپ و منطق گفتگوی صوتی
```

منطق تجاری (محاسبه‌ی بدهی، شماره‌گذاری فاکتور، تطبیق مشتری) عیناً از نسخه‌ی وب
پیاده‌سازی شده تا رفتار اپ برای کاربر یکسان بماند.

## بیلد گرفتن APK

**از طریق GitHub Actions (پیشنهادی — دقیقاً مثل قبل):**
فقط پوش کن؛ ورک‌فلوی `.github/workflows/build-apk.yml` خودش JDK ۱۷ و Android SDK را
نصب می‌کند، Gradle را می‌گیرد (نیازی به فایل باینری `gradle-wrapper.jar` نیست) و
`app-debug.apk` را به‌عنوان Artifact آپلود می‌کند — از تب Actions قابل دانلود است.

**به‌صورت محلی:**
پروژه را در Android Studio (Hedgehog یا جدیدتر) باز کن؛ Gradle Sync خودش همه‌چیز را
می‌گیرد، سپس Run یا Build > Build APK(s).

## چند موتور هوش مصنوعی

از صفحه‌ی تنظیمات می‌توان بین **چت‌جی‌پی‌تی (OpenAI)** و **جمینای (Google Gemini)**
جابه‌جا شد. کلید هر دو جداگانه ذخیره می‌شود (`ai/OpenAIClient.kt` و
`ai/GeminiClient.kt`، هر دو پیاده‌سازِ اینترفیس مشترک `ai/AiClient.kt`)، پس می‌توانید
کلید هر دو را وارد کنید و هروقت خواستید فقط از دکمه‌ی انتخاب موتور استفاده کنید. هر دو
هم برای چت ساختاریافته و هم برای متن‌به‌گفتار ابری استفاده می‌شوند. برای افزودن یک
موتور جدید کافی است یک پیاده‌سازی از `AiClient` بسازید و آن را به `AiProviderType`
اضافه کنید.

## نکات مهم

- **کلید API** از تنظیمات وارد می‌شود و فقط روی خود گوشی (SharedPreferences)
  ذخیره می‌شود؛ داخل کد هاردکد نشده.
- **حداقل نسخه‌ی اندروید:** ۸.۰ (API 26) — به‌خاطر `SpeechRecognizer` و برخی API‌های
  Compose.
- این پروژه در محیطی نوشته شده که به SDK اندروید دسترسی نداشت، پس **کامپایل نشده و
  تست نشده** — اولین بیلد واقعی همان اجرای GitHub Actions یا Android Studio است. اگر
  در بیلد خطایی افتاد، پیام خطا را بفرست تا اصلاح بشه.
